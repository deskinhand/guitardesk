# GuitarDesk

ブラウザで動くギター練習ツールです。インストール不要で、スマホのホーム画面に追加するとアプリのように使えます。

## 機能

- **チューナー**：マイクで音程を検出します。7種類のチューニングに対応し、基準音も鳴らせます。
- **耳コピ**：スピーカーから流れる曲や自分の演奏をマイクで聴き取り、今鳴っているコードとキーを推定します。聴き取ったコード進行はブラウザ内に保存でき、あとからテンポを変えて鳴らせます（音声は保存しません）。
- **トライアド**：3本の弦で弾く3和音のポジションを、転回形ごとに表示します。
- **テンション**：3度を積み重ねたハシゴの図で、9th・11th・13thを足しながらコードの成り立ちを学べます。
- **3音ヴォイシング**：セブンスやテンションコードから音を省いて、3本の弦で弾ける形にします。
- **コード**：コード辞典と、指板で選んだ音からコード名を判定する機能があります。
- **スケール**：12種類のスケールと、ダイアトニック・コードを表示します。

日本語と英語の切り替え、タブの並べ替えにも対応しています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JavaScriptを1つにまとめています） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン |
| `sw.js` | オフライン対応（一度開くと、電波がなくても使えます） |
| `icons/` | アプリアイコン |
| `CNAME` | 独自ドメインの設定（GitHub Pages用） |

## 更新のしかた

1. `index.html` を編集します。
2. コミットしてGitHubにpushすると、数分でサイトに反映されます。
3. オフライン用の保存データを確実に入れ替えたいときは、`sw.js` の `guitardesk-v1` の番号を1つ上げます（例：`guitardesk-v2`）。

## メモ

- チューナーのマイクはHTTPSのページでのみ動きます。GitHub Pagesは自動でHTTPSになります。
- iPhoneはマナーモードのとき、基準音やコードの音が鳴らないことがあります。
